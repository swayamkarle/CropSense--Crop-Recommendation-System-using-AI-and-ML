# 🌱 Crop Prediction & Performance Dashboard

## 📌 Overview

This project is a **Machine Learning-based Crop Prediction System** with an interactive **Performance Dashboard**. It helps in recommending the most suitable crop based on soil and environmental conditions, while also providing clear visualization of model performance using various evaluation metrics.

## 🚀 Features

* 🌾 Crop prediction using Machine Learning
* 📊 Performance metrics (Accuracy, Precision, Recall, F1-Score)
* 📈 Interactive dashboard UI
* 📉 Confusion Matrix visualization
* 🧾 Crop-wise performance table
* 🎨 Modern UI with glassmorphism + animated particle background

  * Potassium (K)
  * Temperature
  * Humidity
  * pH
  * Rainfall
* Output: Recommended Crop

## 📊 Performance Metrics

The model is evaluated using:

* **Accuracy** – Overall correct predictions
* **Precision** – Correct predicted crops out of all predictions
* **Recall** – Correctly identified crops out of actual crops
* **F1-Score** – Balance between precision and recall

## ⚙️ How It Works

1. User inputs soil and environmental data
2. Data is sent to backend (Flask API)
3. Machine Learning model processes input
4. Predicted crop is returned
5. Results + performance metrics displayed on dashboard
